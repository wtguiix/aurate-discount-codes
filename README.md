## The fine print that kills Aurate codes

Aurate's official discount code terms contain several rules that are less standard than you'd expect, and they explain most "my code didn't work" complaints.

**The discount applies to the item with the lowest price in your order.** That's close to the exact wording on Aurate's terms page, alongside language about the discount being "allocated proportionally among all promotional items." In practice, a multi-item cart can produce surprising results — the percentage may not land where you expect. If you're adding a filler item to hit a threshold, check where the discount actually applied before you pay.

**One code per order.** Aurate applies a single discount at checkout. When you're choosing between a percentage code and a fixed amount, do the quick math: on a $250 order, 15% off saves $37.50, so a $50-off code wins; on a $500 order, that same 15% saves $75 and comes out ahead.

**The exclusion list is longer than most people guess.** Aurate's own terms rule out engagement rings, gift cards, the Jewelry First-Aid Kit, and the Aurate Sets category. Deal trackers add that Archive Sale pieces, collaboration and limited-edition collections, Sample Sale items, and Mystery Boxes don't take codes either — the latter two because they're already discounted.

**Minimum-spend thresholds don't count tax or shipping.** If a code requires $1,000, that's $1,000 in merchandise.

**Mixed carts are the single most common failure.** Put an engagement ring and a pair of earrings in the same bag, and the code either fails entirely or only discounts the earrings. The fix costs nothing: place the ring in its own order so each transaction behaves predictably.
